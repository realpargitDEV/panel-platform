Before you start

  • Docker is required to run projects. Panel Platform installs and opens without it, and tells you it is missing rather than failing at launch.
  • Windows 10 (1809+) or 11, 64-bit. Or a 64-bit Linux desktop.

These builds are not code-signed. There is no signing certificate yet, so Windows SmartScreen warns on first run — choose More info then Run anyway. Linux packages carry no repository signature. Every release includes SHA256SUMS.txt if you want to verify what you downloaded: 
# Windows
Get-FileHash .\<file> -Algorithm SHA256

# Linux
sha256sum -c SHA256SUMS.txt --ignore-missing

Updates

The application checks for new releases and offers them; nothing installs until you press the button. Downloads are verified against a signing key built into the application, not one supplied by the release feed.

The .deb cannot update itself — a package manager owns those files, so install the next .deb to upgrade. The AppImage and both Windows installers update in place.
